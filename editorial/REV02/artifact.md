# REV02 조판 기준

설계 원본은 tools/assets/bookk-B5.docx이다. 기존 REV01 및 후반부의 JSON과 DOCX 문장은 모두 일치함을 확인했다. 원본 파일의 SHA-256은 source-baseline.json에 기록한다.

페이지는 원본 첫 구역의 10660×14912 twip(약 188×263mm)이다. 위·좌·우 여백 1588 twip, 아래 2438 twip, 제본 284 twip을 상속한다. 본문 폭 약 127mm, 높이 약 192mm이다. 테마를 보존한다. 예시 문서의 다른 구역은 사용하지 않는다.

본문은 부크크 명조 Light 10.5pt, 제목과 강조는 부크크 고딕 Light, 코드와 입력은 Consolas 10pt이다. 표는 검정 글자·검정 테두리로 한다. 사용자의 서식 지침이 일반 문서 스킬의 표 색상과 상자 금지보다 우선한다.

사용자가 전체 재집필과 흐르는 조판을 요청했다. 따라서 모든 본문 단락, 절 계층, 쪽나눔, 표, 그림 배치, 머리글·바닥글은 편집 대상이다. 제목은 Title, 절은 Heading 1, 소절은 Heading 2를 적용한다. 장별 파일과 부록별 파일은 분리한다. 반복된 절 번호는 한 번만 쓰고 이어지는 제목은 소절로 둔다. 본문은 문단을 쪽 사이에 나눌 수 있으나 제목·첫 문단과 그림·캡션은 붙인다.

명령은 위치·목적·구문·입력·확인 순서로 읽도록 배치한다. 필요한 옵션 설명은 보존한다. 코드와 URL의 글꼴을 줄여 판면에 맞추지 않는다. URL은 원문 문자열을 유지하며 자동 줄바꿈을 허용한다. 그림은 기존 파일을 실제로 삽입하며 원본 비율을 유지한다. 인물 삽화의 기존 프레임 보정은 공통 자산 도구를 따른다.

설치된 부크크 폰트를 확인했다. 문서 스킬의 render_docx.py는 LibreOffice 실행 파일 부재로 실패했다. 기존 장의 검토 때와 같은 대체 경로인 Microsoft Word의 읽기 전용 PDF 출력과 번들 Python의 PDF 렌더러로 내부 QA 이미지를 만든다. 임시 PDF는 build/REV02에만 두며 배포하지 않는다.

검수 항목은 원본 보존, 입력 파일 일치, 참조·자산 존재, 장별 학습 목표와 전이 문제, 기술적 단서의 보존, 모든 출력 지면의 가독성이다. 새로운 공격·VM 변경·UI 촬영을 이 교정의 검증으로 수행하지 않는다.
