4. 피벗: 경보 한 건 → 같은 data.srcip·시간 범위로 넓혀 앞뒤 행동을 시간순으로 묶기(타임라인)

## 문체·형식 (REV01)

- 한다체, 장을 주어로 쓰지 않는다("이 장은" 금지). 추상적 부정 주의문 대신 확인할 필드·동작을 적는다.
- 명령·검색식 블록은 목적 → 입력 → 구문 → 확인 순서이다(`purpose`, `syntax`, `result`). 같은 목적의 짧은 명령은 한 블록에 한 줄씩 넣는다. 줄 길이는 60자 이하로 한다.
- 상자: predict(먼저 예측), caution(주의), blind(보이지 않는 것), field(현장 노트). UI 라벨은 `**굵게**`로 쓴다.
- 장 구성: 도입(시나리오·학습 목표·로드맵·준비와 완료 기준) → 절(흐름 조판) → 장 정리(핵심 정리·확인 문제·해설·더 읽을거리) → 참고 자료(전체 URL)
