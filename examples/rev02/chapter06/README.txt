6장 복사용 예제

B06-*.txt: 브라우저 주소·입력값·Console JavaScript. LAB_DOMAIN은 ccc.com이며 kt66 VM은 192.168.0.107이다.
C06-*.txt: 터미널 명령. 실행 위치와 사전·사후 확인은 manifest.json과 본문에 있다.
Q06-*.txt: Discover DQL. 인덱스·기간을 먼저 지정한다.
paths.txt: Gobuster에 전달할 경로 목록(23행).
records/: 실제 수집 기록과 대응하는 Apache 원문. 학습용 암호를 포함한 URL이 있다.
investigation.txt: 실습 결과 기록 양식.

설치·파일 삭제 명령은 본문의 선행 조건을 읽고 실행한다. 저자용 Python 도구는 독자의 실습 절차가 아니다.

REV02 자료 관리: 책의 고정 실습 주소와 도메인에 맞춰 예제의 해당 문자열을 통일했다.
통일 전 원문과 변경 해시는 editorial/REV02/original-example-values 및 example-value-provenance.json에 보존한다.
주소 통일은 편집 변환이며 새 실습 실행 결과를 의미하지 않는다.
