[C08-01] Windows · 터미널

확인: kt66-bastion과 kt66-siem이 실행 중이고 bastion의 22/tcp가 호스트 2204로 연결된다.

[C08-03] kt66 VM · ccc 호스트 셸

확인: bastion의 root 셸이 열린다. 이후 명령을 VM 호스트에서 실행하지 않도록 hostname으로 위치를 확인한다.

[C08-04] kt66-bastion · root 셸
실습 대상 서버의 이름과 유효 SSH 인증 설정을 확인한다.
hostname은 시스템 이름, sshd -T는 유효 설정을 출력한다. 파이프(|)는 출력을 grep에 전달한다. grep -E는 확장 정규표현식으로 줄을 고른다. 작은따옴표는 검색식의 셸 해석을 막는다. ^는 줄 시작, 괄호는 묶음, 괄호 안의 |는 또는(OR)이다. 끝 공백은 항목 이름을 구분한다. 줄 끝 역슬래시(\)는 다음 줄을 같은 명령으로 잇는다.
hostname
/usr/sbin/sshd -T | grep -E \
'^(port|permitrootlogin|passwordauthentication|maxauthtries) '
확인: hostname은 bastion이며 port 22, permitrootlogin no, passwordauthentication yes, maxauthtries 6을 확인한다. 값이 다르면 이후 실습 조건과 먼저 대조한다.

[C08-05] kt66-bastion · root 셸

/var/ossec/bin/wazuh-control status
tail -n 10 /var/log/auth.log
확인: root 상태 L은 암호 잠금이다. 에이전트 프로세스가 실행 중이고 auth.log에 sshd 기록이 있어야 한다.

[C08-17] 공격자 VM · att 셸
timeout은 뒤 명령의 실행 시간을 제한한다. 45s는 45초이며 시간 만료 종료 코드는 124이다. Hydra -l은 계정 하나, -P는 암호 파일, -t 4는 최대 병렬 작업 수, -w 5는 응답 대기 시간(초)이다. ssh:// 뒤에 대상 주소와 포트를 붙인다.
