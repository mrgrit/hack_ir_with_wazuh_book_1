1장 개별 입력 예제

원고: manuscript/volume01-opening.docx
C01-01.txt부터 C01-51.txt까지 본문의 명령 번호와 대응합니다.
파일을 하나씩 열어 이번 단계의 명령만 입력합니다. 전체 파일을 실행하지 않습니다.
명령이 지면에서 줄바꿈되어 보여도 txt 안에는 한 명령이 한 줄로 저장되어 있습니다.
실행 위치, 조건, 명령의 뜻, 확인할 결과는 본문과 manifest.json을 읽습니다.
설치·중지·종료 명령도 포함되어 있으므로 순서와 조건을 건너뛰지 않습니다.

설정 예시
- env-values.txt: nano로 .env를 편집할 때 참고. 주소·암호·키를 자신의 값으로 교체합니다.
- sysctl-value.txt: 메모리 매핑 한도가 부족할 때만 본문에 지정된 파일에 입력합니다.
설정 예시는 터미널 실행 파일이 아닙니다.

검증 상태
원고와 파일의 일치, 셸 문법, kt66 소스와의 대조를 확인합니다.
새 실습 호스트에서 실제로 설치를 수행한 결과는 아직 포함하지 않습니다.
