1장 복사용 예제

C01-01.txt~C01-51.txt는 본문 명령 번호와 같다.
manifest.json에 실행 위치·목적·확인 기준이 있다.
조건부 명령은 본문에서 해당 조건을 확인한 뒤 실행한다.
기존 kt66 환경에서는 신규 설치 명령을 처음부터 다시 실행하지 않는다.

추가 파일:
- check-env.txt: .env 생성·권한 확인
- return-to-kt66.txt: 로그아웃·재로그인 후 작업 폴더로 이동
- sysctl-value.txt: nano에서 입력할 설정 한 줄(셸 명령 아님)
- urls.txt: 브라우저 주소 예시. IP를 자신의 VM 주소로 바꾼다.
- check-sysctl.txt: 커널 설정 파일 저장 후 내용 확인
