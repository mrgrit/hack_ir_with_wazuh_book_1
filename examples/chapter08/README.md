# 8장 복사용 예제

commands.txt는 위치별 명령 모음이며 전체 실행 스크립트가 아니다. 본문에서 사전 확인·실행·결과를 읽고 한 블록씩 사용한다. dql.txt는 Discover의 wazuh-alerts-*용 검색식이다.

목록 파일은 공격자 VM의 ~/book08에서 사용한다. 대상은 자신의 kt66-bastion이며 예시 주소는 192.168.0.107:2204, 공격자 주소는 192.168.0.108이다. pw-success.txt에는 기본 실습 암호가 들어 있다. 실습 후 삭제한다.

root 임시 허용은 8.5의 백업·검사·복구를 한 묶음으로 수행한다. 8.7의 book08-user는 기존에 없는 이름인지 먼저 확인한다. REV01용 최종본이 아니다.
