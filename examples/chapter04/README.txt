4장 복사용 자료

C04-01~37.txt: 본문의 개별 터미널 명령. 실행 위치는 manifest.json과 본문에 표시한다.
Q04-01~02.txt: Discover의 DQL 검색식.
book04_rules.xml: kt66-siem의 nano에 입력할 사용자 규칙.
ssh-failed.log: 기존 SSH 인증 실패 원문.
ssh-variant.log: 비교 시험용으로 invalid user를 제거한 문장.
collection-test.log: Ruleset Test에 입력할 확인 문구 원문.
collection-before.json: 규칙 적용 전 실제 아카이브 기록.
collection-alert.json: 규칙 적용 후 새로 생성한 실제 경보.
investigation.txt: 실습 결과 기록 양식.

원문·검색식·XML은 지정된 입력란이나 편집기에 붙여 넣는다.
규칙 시험과 실제 로그 생성은 본문의 별도 단계를 따른다.
