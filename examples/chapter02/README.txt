2장 예제 자료

이 장은 공격과 보안관제의 기초를 설명합니다.
- http-request.txt와 http-response.txt: 메시지 일부의 설명용 예시입니다. 서로 대응하는 실제 네트워크 캡처가 아니며, 응답은 특정 kt66 로그인 API의 동작을 보장하지 않습니다.
- ssh-auth.log: SSH 인증 필드 읽기용 합성 로그. 연도 2026, 시간대 Asia/Seoul을 가정합니다.
- case-evidence.csv: 여러 종류의 관찰을 정리한 교육용 합성 조사 자료입니다. 원본 센서 로그 포맷이 아닙니다.
- browser-observation.txt: 자신이 브라우저 UI에서 확인한 내용을 기록합니다.
- case-worksheet.txt: 사건 읽기 실습 답안지입니다. 작성 후 case-answer.txt와 비교합니다.

모든 자료는 텍스트 편집기로 읽습니다. CSV는 스프레드시트로도 열 수 있습니다.
파일을 터미널 실행 스크립트로 사용하거나 Wazuh에 적재하지 않습니다.
파일을 만드는 생성기를 학습자가 실행할 필요는 없습니다. 자료는 저자가 사례별 문장을 작성해 만들었으며 실제 침해를 재현해 채집한 것이 아닙니다.
실제 공격 데이터를 만드는 과정은 해당 공격 장에서 단계별로 다룹니다.
